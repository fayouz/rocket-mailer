## Créer un template

Page **Templates**, puis **Nouveau template** :

- **Nom** et **description** : ce qui s'affiche lors de l'import dans le composeur ;
- **Objet par défaut** : repris dans le composeur si l'objet est vide au moment de l'import ;
- **Partagé** : visible et importable par tous les utilisateurs. Sinon, seul son propriétaire le voit.

L'éditeur GrapesJS (preset newsletter) propose des blocs adaptés aux emails : sections, colonnes, boutons, images, textes. À l'enregistrement, Rocket Mailer conserve :

- le **projet GrapesJS**, pour rouvrir le template dans l'éditeur ;
- le **HTML email** avec les styles **inlinés**, celui qui est importé dans le composeur et envoyé.

## Utiliser un template

Dans le composeur (application ou [composeur embarqué](/embed/overview)) : **Importer un template**, puis recherche et **Importer**. Le contenu remplace le message en cours, après confirmation si le message n'est pas vide. L'utilisateur peut ensuite le modifier librement dans CKEditor.

## Versions

Chaque enregistrement crée une **version** : nom, description, objet par défaut, contenu, mise en page et partage. Le bouton **Historique** liste les versions, avec leur date, leur auteur et les champs modifiés. **Restaurer** remet le template dans l'état d'une version, en créant une nouvelle version : rien n'est perdu.

## Droits

| Action | Qui |
|---|---|
| Voir, importer | Propriétaire ; tout le monde si le template est partagé ; administrateurs |
| Modifier, restaurer, supprimer | Propriétaire, administrateurs |
| Créer | Tout utilisateur connecté (pas depuis le composeur embarqué) |
