### Installer le bundle

```bash [Terminal]
composer config repositories.rocket-mailer vcs https://github.com/fayouz/rocket-mailer-symfony
composer require rocket-mailer/rocket-mailer-bundle:dev-main
```

```php [config/bundles.php]
RocketMailer\Bundle\RocketMailerBundle::class => ['all' => true],
```

### Configurer

```yaml [config/packages/rocket_mailer.yaml]
rocket_mailer:
    url: '%env(ROCKET_MAILER_URL)%'                      # https://mailer.exemple.com
    app_token: '%env(ROCKET_MAILER_APP_TOKEN)%'          # rma_…
    application_id: '%env(ROCKET_MAILER_APPLICATION_ID)%'
    # api_url: http://rocket-mailer-front:3000           # optionnel : URL interne pour les appels serveur
```

```yaml [config/routes/rocket_mailer.yaml]
rocket_mailer:
    resource: '@RocketMailerBundle/config/routes.php'    # POST /rocket-mailer/token
```

Protégez la route comme vos pages : elle agit en tant que l'utilisateur connecté et répond `401` sinon.

```yaml [config/packages/security.yaml]
access_control:
    - { path: ^/rocket-mailer, roles: IS_AUTHENTICATED_FULLY }
```

### Afficher le composeur

```twig [templates/client/show.html.twig]
{{ rocket_mailer_composer({
    to: [client.email],
    template: '0199…',
    variables: { client: { prenom: client.firstName, societe: client.company } },
}, { attributes: { id: 'composer' } }) }}

<script>
  document.getElementById('composer').addEventListener('sent', (e) => {
    Turbo.visit(window.location.href) // ou votre rafraîchissement
  })
</script>
```

La fonction écrit la balise `<script src=".../embed.js">` et le [web component](/embed/web-component). Le brouillon est passé en JSON, échappé.

| Option | Rôle |
|---|---|
| `token_url` | Endpoint de jeton si vous avez changé la route (ex. `path('rocket_mailer_embed_token')` avec un préfixe) |
| `min_height` | Hauteur minimale |
| `attributes` | Attributs HTML supplémentaires (`id`, `class`…) |

## Client

`RocketMailer\Bundle\RocketMailerClient` est un service autowiré. Chaque méthode agit **au nom d'un utilisateur** (`$asUser`, son email).

| Méthode | Rôle |
|---|---|
| `createEmbedToken($asUser)` | Jeton d'embed (déjà exposé par la route du bundle) |
| `sendEmail($asUser, $email)` | Envoie un email : `to`, `cc`, `bcc`, `from`, `subject`, `htmlBody`, `template` (id), `variables`, `attachments` (ids) |
| `uploadAttachment($asUser, $path, $filename, $mimeType)` | Téléverse un fichier (ex. un PDF généré) ; renvoie son `id` |
| `templates($asUser)`, `findTemplate($asUser, $name)` | Templates visibles par l'utilisateur, avec leurs `variables` |
| `email($asUser, $id)` | Un email envoyé (statut, erreur…) |

```php [src/Controller/QuoteController.php]
#[Route('/quotes/{id}/send', methods: ['POST'])]
public function send(Quote $quote, RocketMailerClient $mailer, QuotePdf $pdf): Response
{
    $me = $this->getUser()->getEmail();
    $file = $mailer->uploadAttachment($me, $pdf->renderToFile($quote), "devis-{$quote->getNumber()}.pdf", 'application/pdf');

    $mailer->sendEmail($me, [
        'to' => [$quote->getClient()->getEmail()],
        'template' => $mailer->findTemplate($me, 'Envoi de devis')['id'],
        'variables' => ['client' => ['prenom' => $quote->getClient()->getFirstName()], 'devis' => ['numero' => $quote->getNumber()]],
        'attachments' => [$file['id']],
    ]);

    return $this->redirectToRoute('quote_show', ['id' => $quote->getId()]);
}
```

Pour laisser l'utilisateur relire avant l'envoi, passez plutôt la pièce jointe au composeur : `rocket_mailer_composer({ attachments: [file.id], … })`.

Les erreurs de l'API (variable manquante, adresse refusée, application désactivée…) lèvent une `RocketMailer\Bundle\RocketMailerException`. Elle expose `statusCode` et le message de l'API.
