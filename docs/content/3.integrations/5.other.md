### Un endpoint de jeton côté serveur

Il appelle `POST /api/embed/token` avec le secret et l'email de l'utilisateur **connecté à votre application** :

::code-group
```js [Express]
app.post('/rocket-mailer/token', requireLogin, async (req, res) => {
  const r = await fetch(`${process.env.ROCKET_MAILER_URL}/api/embed/token`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.ROCKET_MAILER_APP_TOKEN}`,
      'X-Impersonate-User': req.user.email,
      'Accept': 'application/json',
    },
  })
  res.status(r.status).json(await r.json())
})
```

```php [Laravel]
Route::post('/rocket-mailer/token', function (Request $request) {
    return Http::withToken(config('services.rocket_mailer.token'))
        ->withHeaders(['X-Impersonate-User' => $request->user()->email])
        ->acceptJson()
        ->post(config('services.rocket_mailer.url').'/api/embed/token')
        ->json();
})->middleware('auth');
```

```python [Django]
@login_required
@require_POST
def rocket_mailer_token(request):
    r = requests.post(
        f"{settings.ROCKET_MAILER_URL}/api/embed/token",
        headers={
            "Authorization": f"Bearer {settings.ROCKET_MAILER_APP_TOKEN}",
            "X-Impersonate-User": request.user.email,
            "Accept": "application/json",
        },
        timeout=10,
    )
    return JsonResponse(r.json(), status=r.status_code)
```

```ts [Next.js (route handler)]
// app/rocket-mailer/token/route.ts
export async function POST() {
  const session = await auth() // votre authentification
  if (!session?.user?.email) return new Response(null, { status: 401 })
  const r = await fetch(`${process.env.ROCKET_MAILER_URL}/api/embed/token`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.ROCKET_MAILER_APP_TOKEN}`,
      'X-Impersonate-User': session.user.email,
      'Accept': 'application/json',
    },
  })
  return Response.json(await r.json(), { status: r.status })
}
```

## Envoyer sans composeur

Depuis votre serveur, `POST /api/emails` avec le même secret et `X-Impersonate-User`, éventuellement un template et ses variables : voir [Emails et templates](/api/emails#avec-un-template-et-des-variables).
