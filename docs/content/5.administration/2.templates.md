## Créer un template

Page **Templates**, puis **Nouveau template** :

- **Nom** et **description** : ce qui s'affiche lors de l'import dans le composeur ;
- **Objet par défaut** : repris dans le composeur si l'objet est vide au moment de l'import ;
- **Partagé** : visible et importable par tous les utilisateurs. Sinon, seul son propriétaire le voit.

L'éditeur GrapesJS (preset newsletter) propose des blocs adaptés aux emails : sections, colonnes, boutons, images, textes. À l'enregistrement, Rocket Mailer conserve :

- le **projet GrapesJS**, pour rouvrir le template dans l'éditeur ;
- le **HTML email** avec les styles **inlinés**, celui qui est importé dans le composeur et envoyé.

## Variables

Une variable est un emplacement remplacé à l'envoi par une valeur propre à chaque email : `{{ client.prenom }}`, `{{ devis.montant }}`… Elles fonctionnent dans le **texte** et dans l'**objet par défaut**.

- **Insérer** : dans un texte, cliquez sur le bouton **{x}** de la barre d'édition, puis choisissez une variable ou tapez-en une nouvelle. Vous pouvez aussi écrire `{{ nom }}` directement.
- **Décrire** : le bouton **Variables** liste les variables du template. Donnez-leur un **libellé** (« Prénom du client »), affiché à la place du nom technique. Donnez-leur aussi une **valeur par défaut** si besoin (« 15 jours ») : sans valeur par défaut, la variable est obligatoire.
- **Nommer** : lettres, chiffres et `_`, avec des `.` pour regrouper (`client.prenom`, `client.societe`).

Les valeurs viennent de l'utilisateur, dans l'encadré **Variables à compléter** du composeur. Elles peuvent aussi venir de l'application qui ouvre le composeur ([`setDraft({ template, variables })`](/embed/prefill-events#variables-de-template)), ou de l'[API](/api/emails#avec-un-template-et-des-variables). Un email ne part jamais avec une variable non remplacée.

::note
Les variables sont faites pour le texte : évitez-les dans les adresses des liens ou des images, que les éditeurs peuvent réencoder.
::

## Utiliser un template

Dans le composeur (application ou [composeur embarqué](/embed/overview)) : **Importer un template**, puis recherche et **Importer**. Le contenu remplace le message en cours, après confirmation si le message n'est pas vide. L'utilisateur peut ensuite le modifier librement dans CKEditor.

## Versions

Chaque enregistrement crée une **version** : nom, description, objet par défaut, contenu, mise en page, variables et partage. Le bouton **Historique** liste les versions, avec leur date, leur auteur et les champs modifiés. **Restaurer** remet le template dans l'état d'une version, en créant une nouvelle version : rien n'est perdu.

## Droits

| Action | Qui |
|---|---|
| Voir, importer | Propriétaire ; tout le monde si le template est partagé ; administrateurs |
| Modifier, restaurer, supprimer | Propriétaire, administrateurs |
| Créer | Tout utilisateur connecté (pas depuis le composeur embarqué) |
