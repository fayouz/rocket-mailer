Un **layout** est l'enveloppe HTML commune à plusieurs templates : logo, en-tête, couleurs, pied de page, mentions légales. Chaque template garde seulement son contenu ; le layout l'entoure à l'import dans le composeur et à l'envoi. Changer le layout met à jour tous les templates qui l'utilisent.

## Créer un layout

Administration → **Layouts d'email**, puis **Nouveau layout**. Partez d'un modèle (« Simple » ou « Bandeau ») ou collez votre propre HTML d'email.

Le HTML doit contenir l'emplacement `{{ content }}` : c'est là que vient le contenu du template. Le bouton **Insérer** `{{ content }}` l'ajoute à la fin du `<body>`. Sans lui, l'enregistrement est refusé.

L'**aperçu** affiche le layout avec un contenu d'exemple. Il est isolé : les scripts ne s'exécutent pas, et les clients mail les ignorent de toute façon.

::tip
Écrivez un HTML d'email classique : tableaux, styles en ligne (`style="…"`), largeur fixe autour de 600 px. Les balises `<style>` sont mal prises en charge par certains clients mail.
::

Un layout peut contenir des [variables](/administration/templates#variables), par exemple `{{ client.prenom }}` dans l'en-tête : elles sont remplies comme celles du template.

## Choisir le layout d'un template

Dans l'éditeur de template, la liste **Layout** propose les layouts existants, ou « Aucun layout ». Le bouton **Aperçu** montre le résultat final, layout compris. Le choix du layout est enregistré dans l'[historique des versions](/administration/templates#versions) du template.

Le contenu du template est inséré dans le layout sans son `<head>` ni son `<body>` : seul le corps compte.

## À l'import et à l'envoi

- **Composeur** : « Importer un template » charge le HTML final, layout compris.
- **API** : un email envoyé avec `template` et sans `htmlBody` utilise le HTML final. `GET /api/email_templates/{id}` renvoie `layout` (`@id`, `id`, `name`) et `renderedHtml`, le HTML final prêt à envoyer.

## Supprimer un layout

Les templates qui l'utilisaient n'ont plus de layout ; leur contenu est conservé.

## Droits

| Action | Qui |
|---|---|
| Voir la liste, choisir un layout pour un template | Tout utilisateur connecté |
| Créer, modifier, supprimer | Administrateurs |

API : `GET`, `POST /api/email_layouts`, `GET`, `PATCH`, `DELETE /api/email_layouts/{id}`.
