Une **boîte partagée** est une [boîte d'envoi](/administration/mailboxes) dont Rocket Mailer **relève aussi les messages reçus**. Ses membres les lisent, y répondent depuis l'adresse de la boîte, se les répartissent et les ferment une fois traités, comme un outil de support léger.

## Activer la réception

1. **Administration → Boîtes d'envoi** : modifiez la boîte et activez **Boîte partagée : relever les messages reçus**. Le serveur IMAP est alors obligatoire (hôte, port, chiffrement, identifiant et mot de passe, vides : ceux du SMTP).
2. Bouton **Membres** (icône des utilisateurs) : ajoutez les utilisateurs par leur adresse. Ils doivent déjà avoir un compte.

| Rôle | Droits |
|---|---|
| **Membre** | Lit les conversations, répond, assigne, ferme ou rouvre, ajoute des notes internes, **envoie depuis la boîte** dans le composeur |
| **Responsable** | Les mêmes, et gère les membres de la boîte |

::note
Les administrateurs gèrent les membres de toutes les boîtes, mais ne lisent une boîte partagée **que s'ils en sont membres** : ajoutez-vous si nécessaire. Une boîte partagée n'est jamais accessible par une application (jeton `rma_…`, impersonation ou composeur embarqué).
::

## Relève

- Le worker relève les boîtes partagées toutes les **5 minutes** (`INBOX_FETCH_INTERVAL`), le bouton **Relever** de la page le fait tout de suite, et la commande `php bin/console app:inbox:fetch` aussi.
- Rocket Mailer ouvre la boîte de réception (`INBOX`) **en lecture seule** : les messages restent sur le serveur, les autres logiciels de messagerie ne voient aucun changement (drapeaux « lu » compris).
- Seuls les messages **nouveaux** sont lus (numéro `UID` au-delà du dernier relevé, par lots de 50). Si le serveur renumérote la boîte (`UIDVALIDITY`), tout est relu et les doublons sont écartés par leur `Message-ID`.
- Un message de plus de **25 Mo** (`INBOX_MAX_MESSAGE_SIZE`) n'est pas téléchargé : la conversation le signale, à consulter dans la messagerie. 20 pièces jointes au plus par message.
- Une erreur de relève (serveur injoignable, mot de passe refusé) s'affiche dans la page et dans l'administration des boîtes.

## Conversations

Chaque message reçu rejoint une **conversation** :

1. celle du message auquel il répond (`In-Reply-To`, `References`), y compris une réponse envoyée depuis Rocket Mailer ;
2. sinon, celle du même sujet (sans « Re: », « TR: »…) avec le même correspondant, sur les 90 derniers jours ;
3. sinon, une nouvelle conversation.

Page **Boîtes partagées** : les boîtes dont vous êtes membre avec leur nombre de conversations non lues, la liste des conversations (recherche dans l'objet, l'expéditeur et le texte ; filtres **Ouvertes**, **Fermées**, **Toutes**, **Les miennes**), puis le fil :

- **Répondre** : la réponse part par le SMTP de la boîte, avec les en-têtes `In-Reply-To` et `References` (le correspondant la voit dans le même fil), et une copie va dans « Envoyés » si la copie IMAP est activée. Elle s'affiche dans la conversation avec son état (en file, envoyé, échec).
- **Note interne** : visible des seuls membres, jamais envoyée.
- **Assigner** à un membre, **Fermer** ou **Rouvrir**. Un nouveau message rouvre une conversation fermée.
- **Non lu** : chaque membre a ses propres marques de lecture ; l'icône d'enveloppe remet la conversation en non lu.

## Sécurité

- Le HTML reçu est **nettoyé côté serveur** (symfony/html-sanitizer) avant d'être enregistré : ni scripts, ni feuilles de style, ni formulaires, ni cadres, ni attributs d'événement, ni liens `javascript:` ; les styles en ligne sont gardés sans ce qui charge une ressource (`url()`, `@import`…).
- Les **images distantes sont bloquées** par défaut (elles révèlent à l'expéditeur que le message a été lu) : bouton **Afficher les images** pour un message.
- Le message s'affiche dans un cadre isolé (`sandbox` sans scripts) avec une politique de sécurité du contenu stricte.
- Les pièces jointes reçues sont stockées dans `ATTACHMENTS_DIR` et **toujours téléchargées**, jamais affichées par le navigateur.
- Les identifiants IMAP restent chiffrés comme ceux des boîtes d'envoi.

## API

Réservée aux utilisateurs connectés (JWT), membres de la boîte. Les applications (un PMS, un CRM…) peuvent aussi lister les conversations, les lire et y répondre : voir [API → Boîtes partagées](/api/shared-inboxes).

| Méthode | Chemin | Rôle |
|---|---|---|
| `GET` | `/api/inbox/mailboxes` | Mes boîtes partagées, non lus et conversations ouvertes |
| `GET` | `/api/inbox/mailboxes/{id}/conversations` | `?status=open\|closed`, `?mine=1`, `?q=`, `?participant=`, `?externalRef=` |
| `POST` | `/api/inbox/mailboxes/{id}/fetch` | Relever maintenant |
| `GET` | `/api/inbox/conversations/{id}` | Le fil (le marque comme lu) ; `?images=1` garde les images distantes |
| `PATCH` | `/api/inbox/conversations/{id}` | `{ "status": "closed", "assignee": "<id>" \| null }` |
| `POST` | `/api/inbox/conversations/{id}/reply` | `{ "htmlBody": "…", "cc": [], "externalRef"?: "…" }`, en-tête `Idempotency-Key` |
| `POST` | `/api/inbox/conversations/{id}/notes` | `{ "body": "…" }` |
| `POST` | `/api/inbox/conversations/{id}/unread` | Remettre en non lu |
| `GET` | `/api/inbox/attachments/{id}` | Télécharger une pièce jointe reçue |
| `GET`, `POST` | `/api/inbox/mailboxes/{id}/members` | Membres (responsables et administrateurs) : `{ "email", "role" }` |
| `PATCH`, `DELETE` | `/api/inbox/members/{id}` | `{ "role": "member" \| "manager" }` |

## Démo

La démo crée la boîte partagée **Contact** (`contact@example.org`), avec `admin@example.org` responsable et `alice@example.org` membre, et quelques conversations. En mode démo (`DEMO_MODE=1`, aussi dans les tests), les messages viennent d'une boîte de réception **en mémoire** : Rocket Mailer ne contacte aucun serveur IMAP réel. Les réponses partent par Mailpit.
