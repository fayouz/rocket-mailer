Par défaut, tous les emails partent par le serveur de la plateforme (`MAILER_DSN`), avec les [adresses d'expédition](/administration/settings) des Réglages.

Une **boîte d'envoi** est un vrai compte email, par exemple `commercial@exemple.com` :

- les emails partent par **son** serveur SMTP, ou par un fournisseur (API) ;
- une **copie** de chaque email est rangée dans son dossier « Envoyés » par **IMAP** : l'équipe les retrouve dans sa messagerie, comme si elle les avait envoyés elle-même ;
- les réponses arrivent dans la boîte.

## Créer une boîte

Menu **Administration → Boîtes d'envoi → Nouvelle boîte**. Une **configuration type** pré-remplit les serveurs :

| Configuration | SMTP | IMAP | À savoir |
|---|---|---|---|
| Gmail / Google Workspace | `smtp.gmail.com:465` SSL | `imap.gmail.com:993` SSL | Mot de passe d'application ; IMAP activé dans Gmail |
| Microsoft 365 / Outlook | `smtp.office365.com:587` STARTTLS | `outlook.office365.com:993` SSL | SMTP authentifié autorisé sur la boîte. Les tenants qui imposent OAuth2 ne sont pas encore pris en charge |
| OVHcloud | `ssl0.ovh.net:465` SSL | `ssl0.ovh.net:993` SSL | |
| Infomaniak | `mail.infomaniak.com:465` SSL | `mail.infomaniak.com:993` SSL | |
| Autre serveur | à renseigner | à renseigner | |

Les champs :

| Champ | Rôle |
|---|---|
| **Nom** | Interne, affiché dans l'administration et l'historique |
| **Adresse**, **Nom affiché** | L'en-tête « De » : `Service commercial <commercial@exemple.com>` |
| **Envoi** | **Serveur SMTP** (hôte, port, chiffrement, identifiant, mot de passe) ou **Fournisseur (API, DSN)** |
| **Copie IMAP** | Serveur, port, chiffrement ; identifiant et mot de passe (vides : ceux du SMTP) ; dossier (vide : détecté) |
| **Applications** | Les [applications](/embed/application) qui la proposent dans leur composeur et peuvent l'utiliser par l'API |
| **Tous les utilisateurs** | La propose aussi dans le composeur de Rocket Mailer |

::note
Les mots de passe et les DSN sont **chiffrés** en base (libsodium) avec `MAILBOX_ENCRYPTION_KEY`, ou une clé dérivée de `APP_SECRET` si elle est vide. Ils ne sont jamais renvoyés par l'API : laissez le champ vide pour garder le mot de passe enregistré. Si la clé change, ressaisissez les mots de passe.
::

### Fournisseurs (API)

Le mode **Fournisseur** accepte un DSN Symfony Mailer. Les fournisseurs suivants sont installés :

| Fournisseur | DSN |
|---|---|
| Brevo | `brevo+api://CLÉ_API@default` |
| Amazon SES | `ses+api://ACCESS_KEY:SECRET_KEY@default?region=eu-west-3` |
| Mailjet | `mailjet+api://CLÉ_PUBLIQUE:CLÉ_PRIVÉE@default` |
| SendGrid | `sendgrid+api://CLÉ_API@default` |
| Postmark | `postmark+api://SERVER_TOKEN@default` |
| Mailgun | `mailgun+api://CLÉ_API:DOMAINE@default?region=eu` |
| Tout serveur SMTP | `smtp://user:pass@smtp.exemple.com:587` |

La copie IMAP reste possible avec un fournisseur : renseignez la boîte IMAP qui doit la recevoir.

### Dossier des copies

Si le champ **Dossier** est vide, Rocket Mailer cherche le dossier que le serveur désigne comme « Envoyés » (RFC 6154), puis un nom usuel (`Sent`, `Sent Items`, `Envoyés`, `[Gmail]/Sent Mail`…). Sinon il crée `Sent`. Un nom saisi est créé s'il n'existe pas.

## Tester

Le bouton **Tester la connexion** (icône prise) :

- **Tester la connexion** : ouvre une session SMTP authentifiée, puis une session IMAP, et indique le dossier des copies ;
- **Envoyer** : envoie un vrai email de test à l'adresse de votre choix, et range sa copie. C'est le seul moyen de vérifier un fournisseur (API).

## Dans le composeur

La liste **De** regroupe :

- les **adresses d'envoi** des Réglages (et l'adresse de l'utilisateur) ;
- les **boîtes d'envoi** de l'application qui affiche le composeur, et celles ouvertes à tous les utilisateurs.

Une application peut aussi en imposer une :

- dans le composeur embarqué : `setDraft({ mailbox: '<id>' })`, ou `setDraft({ from: 'commercial@exemple.com' })` si l'adresse est celle d'une de ses boîtes ;
- par l'API : le champ `mailbox` de `POST /api/emails` (voir [Emails](/api/emails#boîtes-denvoi)).

Une application ne peut **jamais** utiliser la boîte d'une autre application.

## Suivi

Dans **Mes envois** et **Tous les envois**, un email parti par une boîte affiche son nom, et un badge « Copie dans « Envoyés » » quand la copie est rangée.

Si la copie échoue (mot de passe IMAP changé, dossier plein…), l'email **reste envoyé** : l'erreur est affichée dans son détail. Si l'envoi lui-même échoue, l'email passe en « Échec » avec l'erreur du serveur.
