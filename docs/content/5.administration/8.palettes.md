## Thème clair, sombre ou système

Chaque utilisateur choisit son thème avec le bouton en bas du menu (soleil, lune ou écran) : **Clair**, **Sombre** ou **Système**, qui suit le réglage de l'ordinateur. Le choix est gardé dans le navigateur. Les pages de connexion et de configuration initiale ont le même bouton, en haut à droite.

Le composeur embarqué n'a pas de bouton : il suit le réglage du système de l'utilisateur.

## Palettes

Une **palette** est un jeu de couleurs, géré dans Administration → **Palettes** :

| Couleur | Sert pour | |
|---|---|---|
| **Principale** | Boutons, liens, éléments actifs | obligatoire |
| **Secondaire** | Actions secondaires | |
| **Succès** | Envoyé, opérationnel | |
| **Information** | Messages d'information | |
| **Avertissement** | Dégradé, à vérifier | |
| **Erreur** | Échec, suppression | |
| **Gris** | Fonds, bordures, textes : ardoise (bleuté), gris, zinc, neutre ou pierre (chaud) | |

Chaque couleur se saisit en `#rrggbb` ou avec le sélecteur. Une couleur laissée vide garde celle de Rocket Mailer. Les nuances claires et foncées (de 50 à 950, utilisées par exemple en thème sombre) sont calculées à partir de la couleur. L'**aperçu** montre boutons, badges et messages avec la palette, avant d'enregistrer.

## Palette du projet

La palette du projet habille tout Rocket Mailer, y compris la page de connexion. Elle se choisit dans **Palettes** : ouvrez une palette, puis **Utiliser pour le projet**. Le badge **Projet** marque la palette en cours.

**Couleurs par défaut de Rocket Mailer**, en tête de la liste, revient aux couleurs d'origine. Supprimer la palette du projet y revient aussi.

## Palette d'une application

Par défaut, le composeur embarqué d'une application prend la palette du projet. Pour l'accorder aux couleurs de l'application qui l'affiche, choisissez une autre palette dans la page **Applications**, champ **Palette des pages embarquées**. Si cette palette est supprimée, l'application reprend celle du projet.

## Par l'API

| Méthode | Endpoint | Rôle |
|---|---|---|
| `GET`, `POST` | `/api/color_palettes` | Lister, créer `{ "name", "primary", "secondary", "success", "info", "warning", "error", "neutral" }` |
| `GET`, `PATCH`, `DELETE` | `/api/color_palettes/{id}` | Lire, modifier, supprimer |
| `GET`, `PUT` | `/api/theme/project` | Palette du projet ; `PUT { "palette": "/api/color_palettes/{id}" }`, `""` pour les couleurs par défaut |
| `PATCH` | `/api/applications/{id}` | `{ "palette": "/api/color_palettes/{id}" }` ; `null` pour la palette du projet |
| `GET` | `/api/theme?app={id}` | Public : palette à appliquer (`source` : `application`, `project` ou `default`) |

Les palettes sont réservées aux administrateurs ; `/api/theme` est public, car les couleurs ne sont pas secrètes et la page de connexion en a besoin.
