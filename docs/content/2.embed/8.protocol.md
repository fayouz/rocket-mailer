`embed.js` implémente ce protocole pour vous. Cette page sert si vous voulez l'implémenter vous-même, par exemple dans une application mobile hybride, un framework qui gère lui-même ses iframes, ou pour déboguer une intégration.

## L'iframe

```html
<iframe
  src="https://mailer.exemple.com/embed/compose?app=<applicationId>"
  title="Rocket Mailer"
  allow="clipboard-write"
  referrerpolicy="strict-origin"
  style="width: 100%; min-height: 640px; border: 0"
></iframe>
```

## Messages

Tous les messages sont des objets qui contiennent `source: 'rocket-mailer'`.

### De l'iframe vers la page

| `type` | Données | Cible (`targetOrigin`) | Quand |
|---|---|---|---|
| `ready` | — | `*` | L'iframe a chargé la liste des origines autorisées et attend un jeton. |
| `token-request` | — | `*` | Le jeton a expiré : il en faut un nouveau. |
| `loaded` | — | origine de la page | Le composeur est authentifié et affiché. |
| `resize` | `height: number` | origine de la page | La hauteur du contenu a changé. |
| `sent` | `email: { id, subject, to, status }` | origine de la page | Un email a été envoyé. |

`ready` et `token-request` ne contiennent aucune donnée : ils peuvent être diffusés avant que l'iframe connaisse l'origine de la page. Les messages suivants ne sont envoyés **qu'à l'origine vérifiée** de la page.

### De la page vers l'iframe

| `type` | Données | Effet |
|---|---|---|
| `token` | `token: string` | Fournit le jeton d'embed. Réponse attendue à `ready` et `token-request`. |
| `draft` | `draft: Draft` | Applique un brouillon (voir [champs](/embed/prefill-events#champs-du-brouillon)). Pris en compte après `loaded`. |

::warning
Envoyez toujours le jeton avec l'origine de Rocket Mailer comme `targetOrigin`, jamais `*`. Sinon, si l'iframe venait à naviguer ailleurs, le jeton pourrait être intercepté.
::

## Implémentation minimale

```js [integration.js]
const MAILER = 'https://mailer.exemple.com'
const iframe = document.querySelector('#rocket-mailer')

window.addEventListener('message', async (event) => {
  // N'écouter que l'iframe Rocket Mailer
  if (event.origin !== MAILER || event.source !== iframe.contentWindow) return
  const message = event.data
  if (message?.source !== 'rocket-mailer') return

  const send = data => iframe.contentWindow.postMessage({ source: 'rocket-mailer', ...data }, MAILER)

  switch (message.type) {
    case 'ready':
    case 'token-request': {
      const { token } = await fetch('/rocket-mailer/token', { method: 'POST' }).then(r => r.json())
      send({ type: 'token', token })
      break
    }
    case 'loaded':
      send({ type: 'draft', draft: { to: ['client@exemple.com'] } })
      break
    case 'resize':
      iframe.style.height = `${message.height}px`
      break
    case 'sent':
      console.log('Envoyé', message.email)
      break
  }
})
```

## Variante : jeton dans le fragment d'URL

Pour un affichage ponctuel sans JavaScript côté page, le jeton peut être passé dans le **fragment** de l'URL. Le fragment n'est jamais envoyé aux serveurs, et l'iframe l'efface dès sa lecture :

```html
<iframe src="https://mailer.exemple.com/embed/compose?app=<applicationId>#token=<jeton d'embed>"></iframe>
```

Limites de cette variante :

- **pas de renouvellement** : après 15 minutes, l'envoi échoue et il faut recharger l'iframe avec un nouveau jeton ;
- **événements non garantis** : `loaded`, `resize` et `sent` ne sont émis que si le navigateur expose l'origine de la page (`ancestorOrigins` ou `Referer`) et qu'elle est autorisée.

Préférez `postMessage` (ou `embed.js`) dès que possible.
