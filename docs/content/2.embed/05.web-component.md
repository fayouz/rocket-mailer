Le script `embed.js` définit aussi un **web component**, `<rocket-mailer-composer>`. Il fait la même chose que `RocketMailer.mount()`, sans écrire de JavaScript de montage. Il s'utilise tel quel dans n'importe quel framework, ou sans framework.

```html [page.html]
<script src="https://mailer.exemple.com/embed.js"></script>

<rocket-mailer-composer
  application-id="0199a1b2-7c3e-7d41-9f0a-4b2c6d8e1f23"
  token-url="/rocket-mailer/token"
></rocket-mailer-composer>
```

Le composant appelle `token-url` (en `POST`, avec les cookies de votre site) chaque fois qu'il lui faut un jeton. Cet endpoint est celui de l'[étape 2](/embed/token-endpoint) : il doit répondre `{ "token": "…" }`.

::note
La sécurité est la même qu'avec `mount()` : le composeur reste dans une iframe servie par Rocket Mailer, affichable seulement depuis les origines autorisées de l'application, et le jeton ne passe que par `postMessage` vers l'origine de Rocket Mailer.
::

## Attributs

::field-group
  :::field{name="application-id" type="string" required}
  Identifiant (UUID) de l'application déclarée dans Rocket Mailer.
  :::

  :::field{name="token-url" type="string"}
  URL de votre endpoint de jeton. Obligatoire, sauf si vous fournissez la propriété `getToken`.
  :::

  :::field{name="token-method" type="string"}
  Méthode HTTP de l'appel à `token-url`. Par défaut : `POST`.
  :::

  :::field{name="base-url" type="string"}
  URL de Rocket Mailer. Par défaut : l'origine d'où `embed.js` est chargé, donc inutile dans le cas courant.
  :::

  :::field{name="draft" type="JSON"}
  Brouillon initial en JSON, par exemple `draft='{"to":["client@exemple.com"],"subject":"Votre devis"}'`. Pour un brouillon dynamique, préférez la propriété `draft`.
  :::

  :::field{name="min-height" type="number"}
  Hauteur minimale en pixels. Par défaut : `640`.
  :::

  :::field{name="no-auto-resize" type="boolean"}
  Désactive l'ajustement automatique de la hauteur au contenu.
  :::

  :::field{name="frame-title" type="string"}
  Titre accessible de l'iframe. Par défaut : « Rocket Mailer ».
  :::
::

Modifier `application-id`, `token-url` ou `base-url` recharge le composeur. C'est utile, par exemple, quand l'utilisateur de votre application change.

## Propriétés et méthode

| Nom | Description |
|---|---|
| `draft` | Brouillon à appliquer (voir [Pré-remplissage](/embed/prefill-events#pré-remplir-le-message)). Contrairement à `setDraft()` du widget, il peut être défini **avant** que le composeur soit prêt : il est appliqué dès qu'il l'est. |
| `setDraft(draft)` | Même effet que d'affecter `draft`. |
| `getToken` | Fonction qui retourne un jeton (ou une promesse de jeton), à la place de `token-url`. |
| `iframe` | L'iframe du composeur (lecture seule). |

```js [crm.js]
const composer = document.querySelector('rocket-mailer-composer')
composer.draft = {
  to: ['claire@client.example'],
  template: '0199a1b2-…',
  variables: { client: { prenom: 'Claire' } },
}
```

## Événements

Les événements remontent dans le DOM (`bubbles`, `composed`) :

| Événement | `event.detail` | Quand |
|---|---|---|
| `ready` | — | Le composeur est prêt. |
| `sent` | L'email envoyé : `id`, `subject`, `to`, `status` | Après chaque envoi. |
| `error` | Une `Error` | Configuration incomplète, endpoint de jeton en erreur… |

```js [crm.js]
composer.addEventListener('sent', (event) => {
  console.log('Envoyé :', event.detail.subject)
})
```

## Dans un framework

::code-group
```vue [Vue / Nuxt]
<script setup lang="ts">
// nuxt.config.ts : vue.compilerOptions.isCustomElement = tag => tag === 'rocket-mailer-composer'
// Chargez embed.js une fois (app.head.script ou useHead).
const draft = ref({ to: ['client@exemple.com'], subject: 'Votre devis' })
</script>

<template>
  <ClientOnly>
    <rocket-mailer-composer
      application-id="0199a1b2-…"
      token-url="/api/rocket-mailer/token"
      :draft.prop="draft"
      @sent="(e: CustomEvent) => console.log(e.detail)"
    />
  </ClientOnly>
</template>
```

```tsx [React 19]
// React 19 passe les objets en propriétés et les événements "on<nom>" aux custom elements.
export function Composer({ draft }: { draft?: object }) {
  return (
    <rocket-mailer-composer
      application-id="0199a1b2-…"
      token-url="/rocket-mailer/token"
      draft={draft}
      onsent={(e: CustomEvent) => console.log(e.detail)}
    />
  )
}
```

```ts [Angular]
// app.config / module : schemas: [CUSTOM_ELEMENTS_SCHEMA]
@Component({
  selector: 'app-composer',
  template: `<rocket-mailer-composer application-id="0199a1b2-…" token-url="/rocket-mailer/token"
    [draft]="draft" (sent)="onSent($event)"></rocket-mailer-composer>`,
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
})
export class ComposerComponent {
  draft = { to: ['client@exemple.com'] }
  onSent(event: Event) { console.log((event as CustomEvent).detail) }
}
```
::

::tip
Pour une application Nuxt, la [intégration Nuxt](/integrations/nuxt) fournit le composant, l'endpoint de jeton et le chargement du script.
::

## Typage (TypeScript)

```ts [rocket-mailer.d.ts]
interface RocketMailerComposerElement extends HTMLElement {
  draft: RocketMailerDraft | null
  getToken?: () => string | Promise<string>
  readonly iframe: HTMLIFrameElement | null
  setDraft(draft: RocketMailerDraft): void
}

interface HTMLElementTagNameMap {
  'rocket-mailer-composer': RocketMailerComposerElement
}
```

`RocketMailerDraft` est décrit dans [Vue, Nuxt et React](/embed/frameworks#typage-typescript).
