Le widget obtient ses jetons en appelant **votre** backend, jamais Rocket Mailer directement. Votre endpoint :

1. vérifie que l'utilisateur est connecté à **votre** application ;
2. appelle `POST /api/embed/token` avec le **secret de l'application** et l'**email de cet utilisateur** ;
3. renvoie le jeton au navigateur.

::caution
L'identité doit venir de **votre session**, jamais d'un paramètre envoyé par le navigateur. Un endpoint qui accepterait `?user=…` permettrait à n'importe qui d'écrire au nom de n'importe quel collègue.
::

## L'appel à Rocket Mailer

```http
POST /api/embed/token HTTP/1.1
Host: mailer.exemple.com
Authorization: Bearer rma_…
X-Impersonate-User: jean.dupont@exemple.com
Accept: application/json
```

```json [201 Created]
{
  "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiJ9…",
  "applicationId": "0199a1b2-7c3e-7d41-9f0a-4b2c6d8e1f23",
  "expiresAt": "2026-09-24T09:15:00+00:00"
}
```

| Réponse | Cause |
|---|---|
| `201` | Jeton émis, valable `EMBED_TOKEN_TTL` secondes (15 minutes par défaut). |
| `401` `Invalid application token.` | Secret inconnu ou application désactivée. |
| `401` `This application is not allowed to impersonate users.` | L'option « Peut agir en tant qu'utilisateur » n'est pas cochée. |
| `401` `Authentication failed.` | L'utilisateur n'existe pas dans Rocket Mailer ou son compte est désactivé. |
| `403` | En-tête `X-Impersonate-User` absent. |

::tip
L'email est comparé sans tenir compte de la casse. Si vos utilisateurs viennent du même annuaire LDAP que Rocket Mailer, lancez une synchronisation pour que les nouveaux arrivants existent côté Rocket Mailer.
::

## Exemples

::code-group
```ts [Node (Express)]
import express from 'express'

const app = express()
const API = process.env.ROCKET_MAILER_URL // https://mailer.exemple.com
const APP_TOKEN = process.env.ROCKET_MAILER_APP_TOKEN // rma_…

// requireLogin : votre middleware d'authentification (session, JWT…)
app.post('/rocket-mailer/token', requireLogin, async (req, res) => {
  const response = await fetch(`${API}/api/embed/token`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${APP_TOKEN}`,
      'X-Impersonate-User': req.user.email,
      'Accept': 'application/json',
    },
  })

  if (!response.ok) {
    // 401 : utilisateur inconnu de Rocket Mailer, application désactivée…
    return res.status(502).json({ error: 'Rocket Mailer indisponible pour cet utilisateur.' })
  }

  const { token, expiresAt } = await response.json()
  res.set('Cache-Control', 'no-store').json({ token, expiresAt })
})
```

```php [PHP (Symfony)]
<?php

namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\DependencyInjection\Attribute\Autowire;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\Routing\Attribute\Route;
use Symfony\Component\Security\Http\Attribute\IsGranted;
use Symfony\Contracts\HttpClient\HttpClientInterface;

final class RocketMailerTokenController extends AbstractController
{
    #[Route('/rocket-mailer/token', methods: ['POST'])]
    #[IsGranted('IS_AUTHENTICATED_FULLY')]
    public function __invoke(
        HttpClientInterface $client,
        #[Autowire(env: 'ROCKET_MAILER_URL')] string $api,
        #[Autowire(env: 'ROCKET_MAILER_APP_TOKEN')] string $appToken,
    ): JsonResponse {
        $response = $client->request('POST', $api.'/api/embed/token', [
            'headers' => [
                'Authorization' => 'Bearer '.$appToken,
                'X-Impersonate-User' => $this->getUser()->getUserIdentifier(),
                'Accept' => 'application/json',
            ],
        ]);

        if (201 !== $response->getStatusCode()) {
            return $this->json(['error' => 'Rocket Mailer indisponible pour cet utilisateur.'], 502);
        }

        $data = $response->toArray();

        return $this->json(['token' => $data['token'], 'expiresAt' => $data['expiresAt']], headers: ['Cache-Control' => 'no-store']);
    }
}
```

```python [Python (Flask)]
import os
import requests
from flask import Flask, jsonify
from flask_login import login_required, current_user

app = Flask(__name__)
API = os.environ["ROCKET_MAILER_URL"]
APP_TOKEN = os.environ["ROCKET_MAILER_APP_TOKEN"]

@app.post("/rocket-mailer/token")
@login_required
def rocket_mailer_token():
    r = requests.post(
        f"{API}/api/embed/token",
        headers={
            "Authorization": f"Bearer {APP_TOKEN}",
            "X-Impersonate-User": current_user.email,
            "Accept": "application/json",
        },
        timeout=5,
    )
    if r.status_code != 201:
        return jsonify(error="Rocket Mailer indisponible pour cet utilisateur."), 502

    data = r.json()
    response = jsonify(token=data["token"], expiresAt=data["expiresAt"])
    response.headers["Cache-Control"] = "no-store"
    return response
```

```bash [curl]
curl -X POST https://mailer.exemple.com/api/embed/token \
  -H "Authorization: Bearer $ROCKET_MAILER_APP_TOKEN" \
  -H "X-Impersonate-User: jean.dupont@exemple.com" \
  -H "Accept: application/json"
```

## Bonnes pratiques

- **POST et session** : protégez l'endpoint comme n'importe quelle action authentifiée (cookie de session `SameSite`, protection CSRF si votre framework l'exige).
- **Pas de cache** : renvoyez `Cache-Control: no-store`, le jeton est personnel.
- **Pas de stockage** : inutile de conserver le jeton côté serveur. `getToken()` est rappelé automatiquement à l'expiration.
- **Erreurs lisibles** : si Rocket Mailer répond `401` pour cet utilisateur, renvoyez une erreur que votre page pourra afficher (voir `onError` dans [Pré-remplissage et événements](/embed/prefill-events)).
