## Installation

Le script est servi par votre instance Rocket Mailer. Il n'y a pas de paquet npm à installer, et la version du widget suit donc toujours celle du serveur.

```html [page.html]
<script src="https://mailer.exemple.com/embed.js"></script>
```

Il expose un objet global `RocketMailer` avec une seule fonction : `mount()`.

## Monter le composeur

```html [page.html]
<div id="mailer"></div>

<script>
  const mailer = RocketMailer.mount('#mailer', {
    baseUrl: 'https://mailer.exemple.com',
    applicationId: '0199a1b2-7c3e-7d41-9f0a-4b2c6d8e1f23',
    getToken: async () => {
      const response = await fetch('/rocket-mailer/token', { method: 'POST' })
      if (!response.ok) throw new Error('Impossible d’obtenir un jeton Rocket Mailer')
      return (await response.json()).token
    },
    onReady: () => console.log('Composeur prêt'),
    onSent: (email) => console.log('Envoyé', email),
    onError: (error) => console.error(error),
  })
</script>
```

`mount()` insère une iframe dans le conteneur, qui prend toute sa largeur. La hauteur s'ajuste au contenu.

## Options

::field-group
  :::field{name="baseUrl" type="string" required}
  URL de votre instance Rocket Mailer (le front), ex. `https://mailer.exemple.com`. Seule l'**origine** est utilisée : c'est aussi la seule destination à laquelle le widget envoie le jeton.
  :::

  :::field{name="applicationId" type="string" required}
  Identifiant (UUID) de l'application déclarée dans Rocket Mailer. Il détermine les origines autorisées à afficher le composeur.
  :::

  :::field{name="getToken" type="() => string | Promise<string>" required}
  Retourne un jeton d'embed obtenu auprès de **votre** backend (voir [Endpoint de jeton](/embed/token-endpoint)). Appelée au chargement, puis à chaque expiration du jeton. Si elle échoue, `onError` est appelée.
  :::

  :::field{name="draft" type="Draft"}
  Brouillon appliqué dès que le composeur est prêt : destinataires, objet, contenu… Voir [Pré-remplissage](/embed/prefill-events#pré-remplir-le-message).
  :::

  :::field{name="onReady" type="() => void"}
  Le composeur est authentifié et affiché. À partir de ce moment, `setDraft()` est pris en compte.
  :::

  :::field{name="onSent" type="(email: SentEmail) => void"}
  Un email vient d'être envoyé. Voir [Événements](/embed/prefill-events#événements).
  :::

  :::field{name="onError" type="(error: unknown) => void"}
  `getToken()` a levé une erreur ou renvoyé une promesse rejetée.
  :::

  :::field{name="title" type="string" default="Rocket Mailer"}
  Attribut `title` de l'iframe, pour l'accessibilité.
  :::

  :::field{name="minHeight" type="number" default="640"}
  Hauteur minimale de l'iframe, en pixels.
  :::

  :::field{name="autoResize" type="boolean" default="true"}
  Ajuste la hauteur de l'iframe à son contenu. Passez `false` si vous gérez la hauteur vous-même, par exemple dans un panneau à hauteur fixe.
  :::
::

## Valeur retournée

`mount()` retourne un objet de contrôle :

::field-group
  :::field{name="setDraft(draft)" type="(draft: Draft) => void"}
  Remplace les champs fournis du brouillon en cours, par exemple quand l'utilisateur change de fiche client. À appeler après `onReady`.
  :::

  :::field{name="destroy()" type="() => void"}
  Retire l'iframe et les écouteurs. À appeler quand votre composant est démonté ou que vous changez d'utilisateur.
  :::

  :::field{name="iframe" type="HTMLIFrameElement"}
  L'élément iframe, pour le styliser ou le mesurer.
  :::
::

## Plusieurs composeurs, changement d'utilisateur

Chaque appel à `mount()` crée un composeur indépendant. Si l'utilisateur de **votre** application change sans rechargement de page, détruisez le composeur puis remontez-le : `getToken()` produira un jeton pour le nouvel utilisateur.

```js
let mailer

function showComposer () {
  mailer?.destroy()
  mailer = RocketMailer.mount('#mailer', { /* … */ })
}
```

## Mise en page

Le composeur est conçu pour une largeur de 600 px ou plus. Dans un panneau latéral ou une modale, donnez au conteneur une largeur suffisante. Avec une hauteur fixe, passez `autoResize: false` et stylez `mailer.iframe` :

```js
const mailer = RocketMailer.mount('#panel', { /* … */, autoResize: false })
mailer.iframe.style.height = '100%'
```
